# AiBot

منصّة بوتات ذكيّة لواتساب وإنستجرام، عربيّة أوّلاً، متعدّدة المستأجرين.
الخطّة الكاملة في [`docs/plan/`](docs/plan/) — والمخطّط التنفيذيّ في `00-INDEX.md`.

> **الاسم مؤقّت.** `aibot.masaros.net` عنوانٌ تقنيّ؛ المنتج يحتاج اسماً عربيّاً يُنطق ويُتذكَّر.

## الحالة

**المراحل ٠–٥ منجزة جوهريّاً.** ثماني حزم تمرّ من `tsc` نظيفةً مع **120 اختباراً**.

| الحزمة | ماذا فيها | اختبارات |
|---|---|---|
| `packages/shared` | أنواع Zod · قدرات القناة · أكواد الأخطاء | — |
| `packages/crypto` | AES-256-GCM · تدوير بـ`key_version` · بصمات · تنقية السجلّات | 8 |
| `packages/db` | المخطّط (28 جدولاً) · `withTenant`/`withPlatform` · مولّد RLS · البذرة | 9 |
| `packages/channels` | واجهة المحوّل وقدراته · محوّل واتساب · توحيد الأرقام | 18 |
| `packages/ai` | مزوّد Google · التضمين بـ`gemini-embedding-001` · التسعير | — |
| `packages/core` | باني السياق · الحرّاس السبعة · حلقة الوكيل · مُنفّذ HTTP بحدود SSRF | 55 |
| `apps/api` | مصادقة · ويبهوك بمسارَيه · إنبوكس · بوت · `/console` · سوكِت | 14 |
| `apps/worker` | وارد · ردّ · صادر بحارس النافذة · تضمين · مراقبة · حوادث | 16 |

### ما يعمل من طرفٍ إلى طرف

رسالةٌ واردة ← ويبهوك موقَّع ← طابور ← هويّةٌ ومحادثةٌ ونافذة ← تأخير 2000ms بمعرّفٍ
ثابت (دمج المتتاليات) ← بوّابات ← سياقٌ بطبقات ← استرجاعٌ هجين ← حلقة وكيل بأدوات ←
حرّاس ← حارس النافذة ← إرسال ← قياسٌ في `ai_runs` وختمُ فوترة.

### ما بقي

- **`apps/web` فارغ** — لا واجهة. كلّ ما سبق API فقط.
- إشعارات Web Push (VAPID) — الجداول جاهزة والإرسال لم يُكتب.
- معالج تهيئة العميل من 5 خطوات · تقارير العميل · الفريق والدعوات.
- محوّل إنستجرام (المرحلة ٨) — الواجهة والقدرات جاهزةٌ له، يلزم ملفٌّ واحد.
- رفع ملفّات المعرفة (PDF/Word/Excel) واستخراجها.
- `migrate-host.sh` · صفحتا `/privacy` و`/terms`.

## التشغيل محلّيّاً

```bash
corepack pnpm@9.12.3 install          # corepack enable يحتاج صلاحيّة إداريّة على ويندوز
cp .env.example .env                  # املأ الأسرار
docker compose up -d db redis
pnpm --filter @aibot/db run generate  # بعد أيّ تغييرٍ في المخطّط
pnpm dev:api
```

الاختبارات والتحقّق الساكن:

```bash
node_modules/.bin/tsc --noEmit        # داخل كلّ حزمة
node_modules/.bin/vitest run          # داخل كلّ حزمة
```

> `turbo run test` يحتاج `pnpm` على `PATH`. إن لم يكن corepack مفعَّلاً عامّاً،
> شغّل الأمرين أعلاه داخل كلّ حزمة مباشرةً.

## النشر

```bash
ssh mafia-prod
cd ~/aibot && ./deploy.sh
```

`deploy.sh` يتراجع تلقائيّاً عند أيّ فشل، ويأخذ نسخةً احتياطيّة قبل أيّ لمس.

### ⚠️ ثلاثة أشياء مُتحقَّقٌ منها على الخادم — لا تتجاوزها

**١. المنافذ.** استعمل `3070 · 4100 · 5437 · 6385`.
`4080/4081` محجوزة لـBTEC، و`4090/4091` لـ`grade.sbs`، و`6384` لريدِس BTEC.
أعِد الفحص قبل كلّ نشر: `ss -ltn | grep -E ':(3070|4100|5437|6385) '`

**٢. بوّابة الصحّة لا تثق بكود 200.**
`https://aibot.masaros.net/api/health` يردّ **200 الآن** من تطبيق MasarOS عبر
wildcard على `*.masaros.net`. لذلك البوّابة تفحص على `127.0.0.1`، وتطابق
`"service":"aibot"` في الجسم، **و**تطابق `rev` بالالتزام المنشور.

**٣. النفق مُدارٌ محلّيّاً** من `/etc/cloudflared/config.yml` (لا من لوحة Zero Trust).
إعادة تشغيله تقطع **25 مضيفاً** ستّين ثانية — نافذة صيانةٍ متّفقٌ عليها، لا أمرٌ عابر.
وسجلّ DNS لـ`aibot` يُنشأ **من لوحة Cloudflare**: أمر
`cloudflared tunnel route dns` يُنشئ سجلّاً فاسداً لأنّ `cert.pem` مُصدَرٌ لـ`grade.sbs` وحده.

## قواعد لا تُكسر

1. **لا استعلام خارج `withTenant`.** البوّابة الأولى من اثنتين؛ الثانية RLS في القاعدة.
2. **لا شرطَ قناةٍ خارج `packages/channels`.** إن احتجت `if (kind === 'instagram')`
   فالقدرة التي تفحصها ناقصةٌ من `capabilities` — أضِفها هناك بدل الشرط.
3. **لا سرَّ يُعاد للواجهة** — ولا للمالك. بصمةٌ وتاريخٌ فقط.
4. **التوقيع إلزاميّ** على الويبهوك؛ غياب App Secret = القناة معطَّلة.
5. **لا ميزةً لعميلٍ واحد.** إمّا ميزة منصّةٍ للجميع، أو أداة HTTP يعرّفها بنفسه، أو لا.
6. **النشر بـ`deploy.sh` وحده** — و`git pull` لا `git reset --hard`
   (يحذف `docker-compose.override.yml` فتضيع الـvolumes).
7. **لا تغيّر نموذج التضمين** بعد أوّل تضمين: خلط نموذجَين في فهرسٍ واحد لا يُنتج
   خطأً — يُنتج ترتيباً فاسداً بصمت. التغيير = إعادة تضمينٍ كاملة.

## القرارات المعماريّة الأربعة

1. **طوابير بدل مؤقّتات الذاكرة** — إعادة تشغيلٍ واحدة لا تُضيّع رسالة.
2. **أدوات معرَّفة بالبيانات** — عميلٌ جديد بلا نشرٍ جديد.
3. **أسرار مشفَّرة بمفتاحٍ رئيس** — نسخةٌ مسرَّبة لا تكشف توكناً.
4. **سياقٌ بطبقاتٍ خلف منفذ معرفة** — تبديل «حقنٍ كامل» بـ«استرجاع» ملفٌّ واحد.

وخامسٌ أُضيف بعد تصميم القناة الثانية: **هويّةٌ مفتاحها القناة** —
`(tenant_id, channel_id, external_id)` لا `(tenant_id, phone)`، فـ`IGSID`
مواطنٌ من الدرجة الأولى بلا ترحيلٍ لاحق.
